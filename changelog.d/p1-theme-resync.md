### Added

- Syncing the theme again takes the main site's new colours, fonts and shape, keeps every value named in `locked`, and lists what changed, one line per value: "colors.text changed from #2b2118 to #1b1b1f." A locked value says what it kept and what the site uses now. A value you edited by hand without locking it takes the site's value, and the list says so. `khalid theme sync` will print this list in a later release.
