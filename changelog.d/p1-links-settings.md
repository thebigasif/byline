`site.toml` reads a `[seo.links]` table: the `rel` values every link to another site gets (`nofollow`, `sponsored`, `ugc`), whether such links open in a new tab, the affiliate domains whose links are always `sponsored`, and other domains that count as the site itself. A web address where a domain name belongs is refused with a plain message (KH-SEO-10, audit G17).
