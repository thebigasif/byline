### Added

- Writing aids in the admin editor (G50, KH-EDT-1): a slash menu on an empty line that adds any block of plan section 4.6, a details form for each block that also opens on a block already in the post, `@` to mention a post, `[[` to link one with a wikilink, link search on the selected words with Ctrl+K or Cmd+K, and a list of the markdown shortcuts with Ctrl+/ or Cmd+/. Posts with wikilinks now open in the rich-text view. Every link to a post is written as a wikilink, so it keeps working when the post's address changes.
