### Changed

- `khalid staff owner` also shows the sign-in link on `localhost`, where `khalid serve` answers, so the owner can sign in before the site is online. `--listen` names another address, as `khalid serve` takes it. `--json` adds `local_link`.
- `khalid init` says how to make the owner of a server site, and the README and `docs/deploy.md` explain the first sign-in.
