`khalid init [folder] --address <url>` sets up a site from four answers, the website's address, `--mount`, `--languages` and `--mode`, and writes `site.toml`, `routes.toml`, `theme/templates/` and a `content/<language>/posts/` folder per language. It never overwrites an existing site (KH-INS-2, KH-OPS-3).
