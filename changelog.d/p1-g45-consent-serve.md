### Added

- `khalid serve` follows each reader's consent choice: the site's code and a post's own head code run only for a reader who pressed Allow, under the nonce of the page's policy, on every page type, the not-found page included. With `consent = "not-needed"` the code runs for every reader, the not-found page too. `docs/deploy.md` explains `[code]` (G45, KH-SEO-12).
