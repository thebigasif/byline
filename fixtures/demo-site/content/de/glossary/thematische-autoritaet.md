---
term: Thematische Autorität
slug: thematische-autoritaet
translation: topical-authority
---

Thematische Autorität beschreibt, wie sehr eine Suchmaschine einer Website bei einem Thema vertraut. Eine Website erwirbt sie, indem sie das Thema gründlich behandelt, in vielen verlinkten Beiträgen statt auf einer einzigen langen Seite. Wie das geht, steht in [[ein-themencluster-planen]].
