Eine Sitemap ist eine Datei, meist unter `/sitemap.xml`, die die Adressen der Seiten Ihrer Website auflistet. Suchmaschinen lesen sie, um Seiten zu finden, die sie sonst übersehen könnten.

## Was sie leistet

- Neue Seiten werden schneller gefunden, besonders auf einer jungen Website mit wenigen eingehenden Links.
- Sie sagt Suchmaschinen, wann sich eine Seite zuletzt geändert hat, damit sie wissen, was sie neu abrufen sollen.
- Sie verweist auf jede Sprachversion einer Seite, damit der richtige Leser auf der richtigen Version landet.

## Was sie nicht leistet

Eine Sitemap bringt keine Seite nach oben. Eine schwache Seite in der Sitemap bleibt eine schwache Seite. Sie ersetzt auch keine Links: Eine Seite, die nur in der Sitemap steht und auf die keiner Ihrer Beiträge verlinkt, wirkt weiterhin unwichtig. Mehr dazu in [Warum interne Links wichtig sind](/de/blog/warum-interne-links-wichtig-sind/).

## Halten Sie sie sauber

Listen Sie nur Seiten, die in den Suchergebnissen erscheinen sollen. Lassen Sie Entwürfe, Weiterleitungen und Seiten mit `noindex` weg. Eine Sitemap voller Seiten, die dort nicht hingehören, lehrt Suchmaschinen, ihr weniger zu vertrauen.
