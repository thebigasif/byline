Ein interner Link führt von einer Seite Ihrer Website zu einer anderen Seite derselben Website. Das klingt zu einfach, um wichtig zu sein. Es ist sehr wichtig.

## Leser nutzen sie, um weiterzulesen

Wer einen Beitrag zu Ende liest, ist interessiert. Endet der Beitrag ohne Hinweis auf weitere Inhalte, geht der Leser. Ein Link zu einem passenden Beitrag gibt ihm einen nächsten Schritt und Ihnen einen zweiten Seitenaufruf.

## Suchmaschinen nutzen sie zum Finden und Bewerten

Ein Crawler findet neue Seiten, indem er Links folgt. Ein Beitrag, auf den nichts verlinkt, ist schwer zu finden und wirkt unwichtig. Ein Beitrag, auf den zehn andere Beiträge verlinken, wirkt wie etwas, das Ihrer Website wichtig ist. So entsteht [[thematische-autoritaet]].

## So setzen Sie sie gut

- Verlinken Sie aus neuen Beiträgen auf ältere, und ergänzen Sie in älteren Beiträgen Links auf neue.
- Wählen Sie einen Linktext, der sagt, was der Leser bekommt: „so schreiben Sie einen Title-Tag“, nicht „hier klicken“.
- Nutzen Sie für dieselbe Seite immer denselben Linktext. Zeigt eine Formulierung auf zwei verschiedene Seiten, wissen Suchmaschinen nicht, welche gemeint ist.

Fangen Sie mit einem Link pro Beitrag an. Lesen Sie danach zum Beispiel, [wie Sie einen Title-Tag schreiben](/de/blog/so-schreiben-sie-einen-title-tag/).
