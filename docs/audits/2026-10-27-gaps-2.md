# Gap audit 2, 2026-10-27

What this is: every KH-* requirement in `docs/PRD.md` for Phases 1 to 6, the tasks in `docs/phases/`, and `docs/plan.md` sections 4.6 to 4.12, checked against the code and tests on `main` at `352bfc2` (#537). It replaces `docs/audits/2026-10-27-phase-1-gaps.md`, which checked `6a1c3a5`. Phase 7 rows (KH-INS-1, KH-API-6) are listed so nothing is lost, and ranked last.

How to read it: **done** means the PRD acceptance line holds on `main` and a test proves it through the `khalid` binary where the line needs it. **Partial** means part of it is built and tested, often only inside a library crate, and the acceptance line does not hold. **Missing** means nothing on `main` does it. Status lines in `docs/phases/`, changelog fragments and open branches were not counted; only code and tests. Paths shortened: `k/` is `crates/khalid/`, and a crate name alone means `crates/<name>/`.

## Summary

- 69 requirements: 8 done, 51 partial, 10 missing.
- The binary caught up a lot since the first audit. `khalid serve` now runs the SEO head, sitemaps, `robots.txt`, `llms.txt`, feeds and alias redirects (X1, X2), mounts the Content and Admin APIs over SQLite (X5), fires webhooks and IndexNow on publish, and has search, comments, scheduling, preview links, HTTPS, headless and static mode, `doctor`, `keys`, `mcp`, `agents` and `theme sync` and `check`.
- The pattern now is wiring left half done: the library has the feature and its tests, and the binary passes `None` or `Vec::new()` where the feature's input goes. Examples: `build_pages.rs` sets `share_image`, `script`, lead `image`, `sections`, `topics` and `Nav` to nothing; `lint_input.rs` never fills a dozen lint fields, so one block and nine warnings cannot fire through `khalid lint`.
- Nothing proves the public site in CI. `scripts/demo-check.sh` runs vnu, axe and Lighthouse, but no workflow calls it. Three performance budgets are red. Those two gates decide KH-WEB-1 to 7 and KH-OPS-4.
- Phases 4, 5 and 6 are mostly library work or not started: the admin has three screens, the newsletter cannot send mail, the importers are not reachable through `khalid import`.
