Snippets, earlier versions and the live page

Three additions to the editor. A snippet is a group of blocks you save once, such as an affiliate disclosure, and place in many posts: change it once and every post shows the change. Earlier versions let you see what changed and bring back an old text. The live page shows the post in your site's own design while you write.

1. Save the selected blocks as a snippet

Select the blocks, then press "Save as a snippet" under the text. The blocks are replaced by the snippet, so the post keeps showing them.

Save as a snippet

A snippet shows the same blocks in every post that uses it. Change it once and every post changes.

2. A snippet in a post

Type /snippet on an empty line and pick one. In the text it shows as a card; double-click it to pick another.

3. Earlier versions

"Earlier versions" under the post settings. Each save that changes the text keeps the text it replaced. Pick one to see what changed since.
