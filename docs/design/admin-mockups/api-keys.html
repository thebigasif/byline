API keys

An API key lets another program use your blog: your website's code, SerpDad, or a script a teammate runs. Each key can do only what you allow, and you can switch it off at any time.

Create a key

So you know later which program uses it.
What kind of key?

You see a new key only once. Khalid keeps a scrambled copy that nobody can turn back into the key, not even you. Copy it into the other program straight away.

Keys in use

Switching a key off works at once. The program using it is refused from its next request, so make sure it has a new key first.
