Library pictures, your own crop box, and picture search in Settings

Three follow-ups to the editor's picture tools. Add any picture from your media library to a post. Drag your own crop box. See in Settings and in khalid doctor whether photo and GIF search work.

1. A picture from your library in the block menu

Always there, because every blog has a media library.

Add a block

  • Picture from your library A picture you uploaded before
  • Figure A picture with a caption

2. Picking the picture

Newest uploads first. Typing narrows the list to pictures whose name or alt text has the words.

Picture from your library

The picture goes into the post with the alt text and caption saved with it in the library. You can change both in the post afterwards.

An empty library says: "Your media library has no pictures yet. Upload one on the Media screen, then come back."

3. Your own crop box

A fifth shape, "Your own box". Drag the box to move it and the round handle to change its size. The four fields below do the same without dragging, in percent of the picture.

Turn or crop the picture

Saving makes a new copy in the media library and puts it in this post. The original stays, so other posts that use it do not change.

Shape

Turning starts the box again, because the picture's sides change.

4. Photo and GIF search in Settings

A section under the blog's settings. It only shows what is set: the owner changes it in site.toml and the server's environment, because keys never go through the browser.

Photo and GIF search

  • Photos from Unsplash: ready. Writers find photos with /unsplash in a post.
  • GIFs from GIPHY: the key is missing. Writers who search see a message instead of GIFs. Set KHALID_GIPHY_API_KEY on the server and start khalid serve again.

A search that is off says: "Off. Add unsplash = true under [media] in site.toml to turn it on."

5. The same in khalid doctor

Picture search: a problem.
  GIF search on GIPHY is on, but KHALID_GIPHY_API_KEY is not set.
  Writers who look for a GIF see a message instead of GIFs.
  Set KHALID_GIPHY_API_KEY to the API key of a GIPHY app, or set gifs = false under [media] in site.toml.
Picture search: ok. Photo search on Unsplash is on with its key. GIF search on GIPHY is off.
The names and pictures are made up. Doctor checks that a key is set; it does not send the key to Unsplash or GIPHY.
