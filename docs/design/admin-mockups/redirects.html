Redirects

A redirect sends visitors and Google from an old web address to a new one. When you rename a post, a redirect keeps old links working and keeps the post's place in search results.

Send an old address to a post

Khalid writes the old address into the post's file, under aliases:. The redirect then moves with the post, and git keeps a record of it.

It must start with /blog/, the folder your blog lives in.
Visitors land here instead.

This is a permanent move, the kind Google follows and remembers (a 301 redirect).

Old addresses kept in a post's own file are not listed here. Each post shows them under More settings. When you build the blog as plain files, Khalid also writes every redirect into a _redirects file that Netlify and Cloudflare Pages read on their own.

Many redirects at once

A CSV file is a spreadsheet saved as plain text. Each row is one redirect, with the columns from, to, status and match. Khalid stores the whole file or nothing, so a mistake in one row never leaves half a list.
