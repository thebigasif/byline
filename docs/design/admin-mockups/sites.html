Sites on this server

This server runs several blogs, each on its own domain, with its own posts, staff and design. As a super admin you can add one here. It answers at once, with no restart.

Add a site

Khalid makes the new site its own folder and database on this server. Nothing on the other sites changes.

The web address readers type, without https://, such as news.serpdad.com.

Added news.serpdad.com. Khalid serves it now.

Next, point the domain's DNS at this server, the way you did for the home site.

Then give it an owner on the server: khalid --site sites/news.serpdad.com staff owner --email you@serpdad.com --name "Asif"
