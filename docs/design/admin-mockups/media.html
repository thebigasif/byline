Media

The images, videos, sound and files your posts use. Khalid reads each file's content to learn its type, so a program renamed to look like a photo is refused. A file uploaded twice is kept once.

Add a file

A JPEG, PNG or WebP image up to 20 MB, a video up to 100 MB, sound up to 50 MB, or a PDF, ZIP or text file.
Optional. Lowercase words joined by /, such as guides/2026. Leave it empty for the top of the library.
