Writing aids in the editor

Five ways to write faster without leaving the keyboard. Every link to another post is written as a wikilink, [[slug|words]], so it keeps working when the post's address changes.

1. Add a block, then fill in its details

Type / on an empty line, pick "Button", and the details form opens before the block goes in.

Button

A link styled as a button, for the one thing you want readers to do next.

2. Link the selected words to a post

Select "internal links" and press Ctrl K, or ⌘ K on a Mac.

Type to narrow the list. ↑ ↓ to move, Enter to add, Esc to close.

4. Wikilinks

Typing [[ opens the same list. A wikilink shows as a dotted link and is written to the file as you typed it.

That is what topical authority means.
