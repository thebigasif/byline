Khalid admin: mockups for your yes

Seven screens of the admin, drawn before any of it is built. Each one opens in your browser with no internet and no setup. Click around: the menus link to each other, but nothing saves.

Start with the dashboard

The screens, and what to look at

  1. Dashboard

    Does the one blue box tell you the most useful thing to do today? Everything else on the page is quieter on purpose.

  2. Posts

    Filters for checks, review stage and whether Google has the page. Are the three column names clear without help? Added for G52: tick posts and change them together, setting the author or moving them to the trash.

  3. Trash

    Added for G52. Deleted posts wait here. Each one can be put back where it was, or deleted for good after one more question.

  4. Audit log

    Added for G52. Who changed what and when, newest first, for owners and admins. Signed-in staff also see a thin bar at the foot of each blog page with "Edit this post", the post's check result and how often it was read in 30 days; readers never see it.

  5. Blocks in the editor

    A post with blocks opens in the rich-text view, each block a card with its name and one detail. Is the card plain enough to read past while writing?

  6. Editor

    Writing on the left with the slash menu open. Checks on the right: one problem stops publishing, two only warn. Post settings are open here so you can see two new parts: when the post goes live, and a button that copies a preview link to share the draft. Does the long title wrap onto a second line instead of running off the edge?

  7. Design

    The colours and fonts theme sync copied from your main site, each with its readability score and a tick box to keep it the next time you sync.

  8. Redirects

    Sending an old address to a post, the addresses that found nothing with a one-step fix, the redirects Khalid keeps, and CSV in and out. The page explains what a redirect is before it asks for anything.

  9. Analytics

    Added on 31 Oct 2026. Page views against the days before, where readers came from, the readers each AI assistant sent, and the pages AI bots read but never cite. Is each word explained before you need it?

  10. Search Console

    Added on 31 Oct 2026. The long searches, the way people ask AI assistants, that showed each post, and the heading that answers each or "No heading yet". Is it clear what to write next?

  11. API keys

    The three kinds of key in plain words, the warning that a key is shown only once, and what switching one off does.

  12. Settings

    Name, address, how visitors get the pages, and languages. The warning about changing the address sits right next to the fields.

  13. Media

    Added for task G51. Uploading a file, the library with the images still missing alt text one click away, and a details page for alt text, caption, folder and the focal point every crop keeps.

  14. Sign in and start a post

    Added for your yes after the first seven. Signing in with a staff token, with the message a wrong one gets, and the first screen after it until the Dashboard can list posts.

  15. Editor: score, search result and schema

    Added for G54. The score sits beside the checks and points at them. Below it, the post as a Google result, the title and focus keyword that shape it, and the schema the page carries, with a field for your own.

  16. Schema templates

    Added for G54. One kind of schema for every post in a collection, such as a Course for every guide. Does the opening say what schema is before it asks for anything?

House rules every screen follows

  • Light theme only. There is no dark mode.
  • One blue button per screen: the main thing to do there.
  • A screen that asks for a decision explains it first, and says what happens next.
  • Real posts, authors and messages from the demo site, never filler text. Each page's footer says where an example stands in for real data.
  • Text in Inter when your computer has it, the system font otherwise. Every colour pair passes WCAG AA, the web's standard for readable pages.
  • Works at phone width, by keyboard alone, and with no scripts at all.
