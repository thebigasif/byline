Who else is editing, and tables as a grid

Two additions to the editor. When two people open the same post, the first one writes and the second one reads, so nobody types over somebody else. And a table opens as a grid of cells you fill in, instead of lines of markdown.

2. Someone else holds the post

The text is locked, so you can read but not type. The box says who is writing, why the text is locked, and what taking over does before it offers it.

Maria is editing this post

You can read it, but not change it. It is locked so two people never overwrite each other. It opens for you when Maria closes it.

Taking over locks it for Maria instead. Anything Maria has not saved yet is not kept.

3. A table in the text

A table shows as a card. Double-click it, or select it and press Enter, to open the grid. Type /table on an empty line to add a new one.

4. Editing the table as a grid

Each cell is a box you type in. Tab moves to the next cell. The buttons add or remove a row or a column at the end.
