# Name checks: Byline, Masthead, Dateline, Gazette, Typeset, Lede, Stylebook

**Status:** decided. Dateline is the working name, pending a trademark lawyer and the founder's veto; the reasons are in `docs/decisions/2026-10-26-cto-answers.md`, section 1. Lede and Stylebook were checked afterwards as fallbacks, so a lawyer's no does not cost a week. This page adds facts only. Phase 0, task 0.1.

These checks were run on 2026-10-26. GitHub was checked with `gh api users/<name>` and `gh search repos <name> --limit 10`. crates.io and npm were checked through their public APIs. Domains were checked through RDAP at rdap.org (200 means registered, 404 means no record found), and each registered domain's homepage was fetched once to see what it serves. Trademarks and existing products were checked through web search only. The USPTO and TMview search sites need a browser, so their checks are only partial. Nothing was registered, submitted or signed in to.

"Free" below means no record was found today. It is not a promise the name can be registered or used.

## Notes per name

**Byline.** This is the most crowded name in our own space. Byline CMS ([GitHub](https://github.com/Byline-CMS/bylinecms.dev), [site](https://bylinecms.app)) is an open-source headless CMS in TypeScript under MPL-2.0. It had a commit on 2026-10-25 and describes itself as stable at v4. It also holds bylinecms.dev and bylinecms.app. byline.com is Byline Times, a UK reader-funded newspaper. "Bylines" is also a well-known WordPress multi-author plugin family ([Co-Authors Plus](https://github.com/Automattic/co-authors-plus), [humanmade/bylines](https://github.com/humanmade/bylines)). The crate name is free. Alternative domains checked: getbyline.com, bylinecms.com and bylinehq.com are all registered.

**Masthead.** The GitHub name belongs to an Indian software company. "Mastheads" (plural) is a paid AI editorial platform aimed at publishers, which is close to our space. The crate name is free. Alternative domains checked: mastheadcms.com and getmasthead.com are both registered.

**Dateline.** The quietest name in software. dateline.dev had no RDAP record, which suggests it may be available. The crate name is free. The npm package is a small, still-maintained date formatting library. NBC's "Dateline" TV programme is a famous brand. Its trademark classes were not checked, so ask about it during the hand check. Alternative domains: getdateline.com and datelinecms.com had no RDAP record.

**Gazette.** Every registry name is taken, though the crate and npm packages are small. gazette.dev and the GitHub org belong to Gazette, an open-source streaming broker project. The word is a common noun for newspapers and official journals, so it is used widely and may be hard to protect. Alternative domains: gazettecms.com had no RDAP record. getgazette.com is registered.

**Typeset.** Every registry name is taken. The crate has real use (19k downloads). The strongest conflict is the Typeset brand that SamCart now owns, which filed a US class 42 application for TYPESET in 2023 for design-content SaaS. Typesetter is a separate PHP flat-file CMS with a similar name, last pushed in 2022. Alternative domains: gettypeset.com and typesetcms.com had no RDAP record.

**Lede (fallback, checked later the same day).** Taken on GitHub, crates.io, npm and both domains. The strongest conflict is Lede, a publishing platform for journalism startups built by Alley Interactive, which is in our own category. A "lede" is the opening of a news story. Alternative domains: lede.io and ledecms.com had no RDAP record. getlede.com is registered.

**Stylebook (fallback, checked later the same day).** The crate name is free. Everything else is taken, but by small projects. The real weight is the AP Stylebook: a famous editorial brand that also sells software, so a lawyer should look at it first. Alternative domains: stylebook.io, getstylebook.com and stylebookcms.com had no RDAP record.

## Checks to finish by hand

USPTO search does not answer scripts, and web search only finds old copies. Search each word, then filter for classes 009 and 042 and live status:

- USPTO trademark search: https://tmsearch.uspto.gov/search/search-information (search BYLINE, MASTHEAD, DATELINE, GAZETTE, TYPESET, LEDE, STYLEBOOK one at a time)
- TMview, which includes EUIPO and national offices: https://www.tmdn.org/tmview/#/tmview (set "Nice class" to 9 and 42, and "Offices" to EM for EUIPO)
- EUIPO eSearch plus as a second source: https://euipo.europa.eu/eSearch/
- Current status of US application 98115573 (TYPESET): https://tsdr.uspto.gov/#caseNumber=98115573&caseType=SERIAL_NO&searchType=statusSearch
- Who owns masthead.com and dateline.com and what they serve. Both did not load for a script: open https://masthead.com and https://dateline.com in a browser.
- Whether dateline.dev, getdateline.com, datelinecms.com, gazettecms.com, gettypeset.com and typesetcms.com can be bought: check at a registrar such as https://www.cloudflare.com/products/registrar/ without buying.
- A trademark lawyer should confirm any shortlisted name before launch. These notes are not legal advice.
