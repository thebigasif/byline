# khalid-core

Shared building blocks for [Khalid](https://github.com/thebigasif/khalid), the blog engine by SerpDad: user messages with what, why and fix, slugs and other identifiers, the clock, typed site settings and safe site paths. `khalid-lint` depends on it.

The `test-util` feature adds test doubles such as a fixed clock. Leave it off in normal builds.
